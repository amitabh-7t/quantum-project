Place the four CSVs from the Kaggle dataset "Solar Power Generation Data" in this directory:

- `Plant_1_Generation_Data.csv`
- `Plant_1_Weather_Sensor_Data.csv`
- `Plant_2_Generation_Data.csv`
- `Plant_2_Weather_Sensor_Data.csv`

Then, from `src/`, run `python build_labeled.py` to write `labeled.pkl` here. The CSVs and the pickle are gitignored.
